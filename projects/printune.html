Printune: build Microsoft Intune printer packages

Printune is a browser-based toolkit that helps IT administrators prepare consistent Microsoft Intune Win32 deployments for local TCP/IP printers.

The problem it addresses

Printer deployments can become inconsistent when each queue is packaged by hand: driver, port, installation commands and Intune detection settings all need to agree. Printune brings those inputs together and generates deployment scripts and configuration details for administrators to review.

It aims to reduce repetitive setup work and make printer deployments easier to reproduce across managed Windows devices.

How it works

  1. Enter a printer name, TCP/IP address or hostname, port name and driver information.
  2. Select a pre-configured model when available, or supply a driver ZIP and INF details manually.
  3. Review the generated install and uninstall commands and registry detection settings.
  4. Download the package, prepare it with Microsoft's Win32 Content Prep Tool, then upload the resulting .intunewin file to Intune.

Package contents and capabilities

Driver and queue setup

The generated package can include install and uninstall scripts and the selected printer driver archive. Configuration supports local TCP/IP ports and named printer queues.

Flexible driver configuration

Use a pre-configured model or enter the exact driver model name and INF filename. The installer searches extracted packages for driver files under common architecture folders such as x64 and amd64.

Printer defaults

An optional exported printer configuration can carry supported global defaults, such as paper size, colour and duplex settings, into deployment.

Intune settings

Printune provides example install and uninstall commands plus a registry-based detection rule for the deployed printer queue. The package can be installed in the System context through an Intune Win32 app.

Driver publisher trust and troubleshooting

For applicable signed drivers, an optional switch validates the catalogue signature and certificate chain before trusting that publisher. The project also documents installation logs, SetupAPI diagnostics and common error codes.

Testing and safe deployment

Printer drivers vary in INF structure, signing, supporting files and behaviour. Test each generated package on a representative Windows device before broad deployment, then verify the queue, port, defaults, detection rule and uninstall behaviour in your environment.

The uninstall script removes the requested queue and only removes a port when no other printer is using it. Driver packages and publisher certificates are retained because other queues may still depend on them.

What this project demonstrates

  • Turning a repeated endpoint-management task into a guided configuration workflow.
  • Preparing PowerShell install and uninstall logic for Intune Win32 apps.
  • Accounting for driver signing, detection, logging and rollback considerations.
  • Documenting steps so an administrator can review and test a package before deployment.

Try it and explore the source

The live app is available at printune.jongens.nz. The GitHub repository contains source code, setup instructions, a configuration guide and issue tracker.
